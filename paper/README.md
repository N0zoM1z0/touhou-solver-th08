# TH08 Solver Paper

`main.tex` is the concise English design and experimental argument for the
source-authoritative Sakuya/Remilia Lunatic Route-2 solver.  It intentionally
summarizes mechanisms and conclusions instead of duplicating route ledgers.

Build, when a TeX distribution is available:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

Generated TeX files and the PDF are ignored; the reviewed source is tracked.
