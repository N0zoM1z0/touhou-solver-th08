# TH08 Research Log — 2026-08-25

## Retained-root capture exposed a Practice/Spell-Practice identity error

- **Attempt:** `lunatic_route2_stage5_unattended_20260825_010248` ran in the
  dedicated TH08 Wine prefix/display with Lunatic Sakuya/Remilia Stage 5,
  hard no-Bomb, capture-only future-source retention, and nonbinding
  86,400/86,700-second agent/trial limits.
- **Physical observation:** at gameplay frame 0 the relocated ECL image was
  47,224 bytes and normalized to SHA-256 `3148f45f...`, exactly decoded
  `ecldata5.ecl`. The command had incorrectly pinned 31,184-byte
  `ecldata5sp.ecl` SHA-256 `d9140821...`. Exact identity failed closed, so the
  trial produced no decisions and no retained producer root. It stopped in
  about 17 seconds because of identity, not duration; exact-prefix cleanup
  reported no leftovers.
- **Source root cause:** `GameManagerFlags` names bit 0 `isPracticeMode` and
  bit 14 `isSpellPractice`. `EnemyManager::AddedCallback` branches on bit 14,
  not bit 0. Practice Start uses `g_StageEclFiles` just like route play;
  stage-scoped Spell Practice below card 205 uses `g_StageSpellEclFiles`.
- **Correction:** Practice Start identities now equal the route identities.
  The former `*sp.ecl` table is retained under the explicit
  `STAGE_SPELL_PRACTICE_ECL_IDENTITIES` name for static cross-package producer
  checks. The corrected producer contract is schema v2 and no longer calls
  `*sp.ecl` a Practice Start image.
- **Verification:** 56 focused tests pass. The next action is the same isolated
  root capture with the corrected `ecldata5.ecl` identity; no algorithmic or
  hit-count claim follows from this infrastructure repair.
