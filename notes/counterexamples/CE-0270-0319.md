# TH08 Counterexamples CE-0270–CE-0319

## CE-0270 — Offline beam replay used the wrong hazard epoch

**2026-08-26; audit-infrastructure bug fixed offline.** Live decisions retain
observation-to-input age separately from player-to-hazard lag and the complete
discrete bullet-age support. `local_beam_stability_audit.py` instead supplied
the observation age as local `snapshot_lag` and omitted bullet-age support.
After the source-authoritative bullet clock correction this replayed a
different geometry root while presenting it as a same-row policy comparison.

Resolution: the flat planner wrapper now accepts the explicit bullet support;
the audit reads both local clock values from `hazard_alignment` and fails
closed if either is absent. An eight-root replay of the corrected-age Easy
trace matches all eight recorded actions. One same-action hard vector still
differs at frame 57590 (`6` versus `3` accumulated collisions with essentially
identical penetration), so exact same-row hard-vector reproduction remains an
open diagnostic rather than a claimed policy result.

## CE-0271 — A scan counter was mistaken for current pool occupancy

**2026-08-26; unsafe shortcut rejected, source-layout bug fixed offline.** The
live synchronous prefix read starts at historical `ENEMY_POOL_BASE`, which the
authoritative manager layout proves is `enemies[1]`. Native slot zero arrives
only through the roughly 91 ms asynchronous sparse scan or the boss guard, and
that sparse worker is resubmitted every four game frames. Merely deleting it
would leave an uncertified tail and stale slot-zero geometry.

The first proposed resolution compared prefix active flags with
`EnemyManager::EnemyCount`. Source inspection falsifies that certificate:
`OnUpdate` resets the field immediately before the ascending scan and
increments it before updating each encountered active slot. An encountered
enemy can die later in its update, while an ECL child can occupy a lower slot
after that slot has already been scanned. Equal counts can therefore be
offsetting and do not prove tail absence.

Resolution: the generic `source-contiguous` profile reads native slots 0--63
synchronously and retains complete slots-0--479 background coverage, replacing
the scalar scan with one contiguous 10.3 MiB read into a reusable buffer. Easy
selects the existing local-only path when ordinary global authority is off,
but still owns the background enemy worker. The old trace's maximum serialized
body slot is 32; this is workload evidence only. Physical latency and survival
effects remain unclaimed pending a Wine benchmark and complete Easy route.
